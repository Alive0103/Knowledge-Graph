# 毕业论文完整稿修订说明

## 1. 本轮修订目标

本轮修订以 `毕业论文-完整稿-2026-04-10.md` 为主文件，目标是将摘要、正文主体章节与结论部分继续推进到更接近“终稿提交版”的成熟度，并对照 `毕业论文-正文.md` 吸收其中可取但不失真的内容。

## 2. 已吸收的可取之处

1. **问题分层更清晰的叙述方式**  
   参考 `毕业论文-正文.md` 中对“知识分散、离线约束、实体歧义、跨语言割裂”的分层表达，对摘要和绪论中的问题定义进行了重写，使研究动机更集中。

2. **为什么这样设计的解释方式**  
   吸收了原正文中“为什么不把RAG写成主实验”“为什么同时保留两条对齐基线”“为什么采用一跳邻域而不是更深图模型”等解释性写法，并改写为更审慎的论文语言。

3. **图表占位的功能性说明**  
   保留并强化了图表占位的作用说明，使图1.1、图2.1、图3.1至图4.3不只是“有图”，而是明确说明图应服务哪段论证、突出哪些信息。

4. **主线与补充线的写法**  
   将实体对齐部分进一步明确为“LaBSE 主线 + BGE-M3 补充强基线”的分析结构，这一写法来自对原正文稿优点的吸收，但已改写为更符合当前正式结果口径的版本。

## 3. 明确没有直接吸收的内容

以下内容在 `毕业论文-正文.md` 中虽然出现，但本轮没有直接写入完整稿，原因是与当前正式实现或正式结果口径不完全一致，或缺少足够硬的证据支撑：

1. `Chinese-RoBERTa-wwm-ext-large` 被写成当前正式主线NER基座模型；
2. “约两万个实体”“2828/2844页面”“5796个索引实体”“99.8%向量覆盖率”等尚未在完整稿当前证据链中统一核实的具体数量；
3. “98.2%描述填充率”“95.7%别名填充率”等无法稳定追溯到正式汇总的统计值；
4. 一些更像探索性方案的系统模块表述，例如把意图驱动检索、动态混合策略或完整RAG闭环写成既成主结论；
5. 部分参考文献条目与表述方式中较强的“先写满、后核证”痕迹。

## 4. 当前完整稿的写作原则

1. 正式实现与正式结果优先以 `Knowledge-Graph/retry` 和 `retry/output/` 为准。
2. 实体链接与跨语言实体对齐仍然是论文主实验主线。
3. 离线知识组织写作定位为前置支撑层，而不是单独割裂的辅助章节。
4. `kg_rag` 写作定位为系统支撑层与应用落点，不夸大为已完成闭环生成评测。
5. 对没有硬证据的数字、模型名和结论一律宁可保守，不做冒进陈述。

## 5. 后续建议

1. 若后续继续打磨附录、图表说明或答辩稿，可延续本轮方法：先保证证据一致，再提升语言成熟度。
2. 若最终需要转成学校版Word论文，建议再做一轮“术语统一 + 图表标题统一 + 参考文献格式统一”的专项整理。
3. 若后续核实出更硬的实体规模、索引规模或数据覆盖率统计，可再考虑补回摘要和第3章中对应表述。
