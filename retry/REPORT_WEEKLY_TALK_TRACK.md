这周我主要把实体对齐这条实验链重新整理并恢复起来了。首先，我核对并恢复了 `DBP15K zh_en` 数据，确保实体、关系、三元组以及训练集、验证集、测试集这些文件能够被统一读取。然后我补了查询工具，已经可以做到由编号查实体、由编号查关系、按实体查看相关三元组，以及按关系检索三元组，这样后续分析模型预测结果时就不再只是看数字编号。

## 2. 当前已经完成的实验结果

目前在 `DBP15K zh_en test` 上，我已经完成四组有意义的结果：

| 方法 | MRR | Hits@1 | Hits@5 | Hits@10 |
| --- | ---: | ---: | ---: | ---: |
| Raw LaBSE baseline | 0.478 | 0.410 | 0.559 | 0.606 |
| Raw BGE-M3 baseline | 0.679 | 0.624 | 0.745 | 0.776 |
| LaBSE + neighbor graph model（现有旧权重） | 0.690 | 0.621 | 0.773 | 0.810 |
| LaBSE + neighbor graph model（本次从零重训） | 0.696 | 0.631 | 0.773 | 0.810 |

如果按照老师要求重点比较“对齐前后”，那么主线结论就是：以 `Raw LaBSE baseline` 作为对齐前结果，图结构增强后的模型可以把 `MRR` 从 `0.478` 提升到 `0.690` 或 `0.696`，把 `Hits@1` 从 `0.410` 提升到 `0.621` 或 `0.631`。这说明邻居图结构信息对跨语言实体对齐确实有明显帮助。

## 3. 这次重训结果怎么表述最严谨

这次我不仅完成了仓库中原有 `final_model.pth` 的复现评测，也在 `retry/` 里完成了新的从零重训。新训练任务一共跑了 `150` 个 epoch，最优出现在第 `147` 个 epoch，选择指标是 `valid_hits@1`。最终新权重在测试集上达到 `MRR=0.696`、`Hits@1=0.631`，比仓库原有旧权重结果 `MRR=0.690`、`Hits@1=0.621` 还有小幅提升。

所以现在可以很明确地区分两件事：一是“已有模型权重的严格复现评测”已经完成；二是“新模型从零重训并完成评测”也已经完成。这比之前只做旧权重复现更完整，也更符合科研汇报的严谨性。

## 4. 如果老师追问，可以这样回答

如果老师问“训练对是什么”，可以回答：训练对就是跨语言实体对齐里已知的对应实体对，例如一个中文实体 ID 和一个英文实体 ID，告诉模型这两个实体本来就是同一个对象，用来提供监督信号。

如果老师问“现在有没有多种方法对比”，可以回答：现在已经有 `Raw LaBSE baseline`、`Raw BGE-M3 baseline`、`LaBSE + neighbor graph model（旧权重）` 和 `LaBSE + neighbor graph model（新重训权重）` 四组结果，可以同时展示文本向量基线、图增强模型，以及旧模型和新模型的差异。

如果老师问“BGE-M3 为什么还没有对齐后的图模型结果”，可以回答：因为当前图增强模型是按 `LaBSE 768 维表示` 训练的，`BGE-M3` 目前完成的是原始文本向量基线。如果要做 `BGE-M3 + graph`，需要重新生成实体向量并重新训练邻居图模型，这部分可以作为下一阶段扩展实验。
